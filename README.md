📊 Smart Finance Dashboard

An interactive Streamlit web application that analyzes credit card transaction data and user financial profile to provide spending insights, credit card suggestions, and loan recommendations.

The system uses a trained machine learning model to predict spending behavior and combines it with eligibility rules (income, credit score, credit limit) to recommend suitable financial products.

Features

Upload credit card statement (CSV) for spending analysis

Predict future spending using ML model

Monthly & category-wise spending visualization

Credit utilization and financial health insights

Personalized credit card recommendations

Loan recommendations based on eligibility

Tech Stack

Streamlit, Pandas, NumPy, Scikit-learn, Matplotlib, Seaborn, Plotly, Joblib
